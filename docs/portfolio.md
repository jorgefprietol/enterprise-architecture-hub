# Experiencia de proyecto

**Enterprise Architecture Hub — Arquitectura empresarial y desarrollo full stack**

Diseño y desarrollo de una plataforma para traducir objetivos estratégicos en capacidades, decisiones de arquitectura e iniciativas de inversión. Implementación de un catálogo gobernado en C# / ASP.NET Core, un motor de priorización en Java / Spring Boot y un panel ejecutivo en React / TypeScript.

- Modelado de capacidades en cinco niveles con validación de alcance, responsables y tipos de equipo.
- Evaluación de madurez por dimensión con evidencia, mapa de calor y objetivos de mejora.
- Trazabilidad bidireccional entre objetivos, capacidades, procesos, datos, aplicaciones y tecnología.
- Priorización explicable mediante impacto, brecha de madurez, viabilidad y alineación estratégica; escenarios presupuestarios.
- Hoja de ruta trimestral con dependencias, presupuesto y criterios de resultado, además de decisiones con contexto y consecuencias.
- Persistencia relacional, auditoría transaccional, APIs documentadas, pruebas de integración y E2E.
- Contenedores ejecutados sin root y pipeline de GitHub Actions para validar y publicar imágenes con SBOM y procedencia.

**Tecnologías:** C#, .NET 10, EF Core, SQLite, Java 21, Spring Boot, React, TypeScript, Vite, Nginx, Docker Compose, GitHub Actions, GHCR, xUnit, JUnit y Playwright.

Este texto describe la experiencia técnica implementada en el repositorio. Las cifras del caso Meridian son ficticias; no se atribuyen clientes, cargos laborales, años de experiencia, mejoras comerciales verificadas ni despliegues empresariales no demostrados.
